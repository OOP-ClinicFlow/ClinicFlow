# ClinicFlow
A clinic queue management system built with Java and Javalin — register patients, issue unique tickets, track statuses, and manage urgent cases digitally.

## Project structure

```text
pom.xml
src/
  main/
    java/
      App.java
      zm/clinic/
        Main.java
        Patient.java
        QueueTicket.java
    resources/
      public/
        app.js
        index.html
        style.css
```
